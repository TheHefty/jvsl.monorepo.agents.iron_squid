## Summary

Anyone who opens a run's link sees that run, read-only, and their own run is left alone.

## Why

A shared link is the community's view of a run. Delivers FR-41, FR-42 and FR-44. The link is input
from a stranger, so a malformed, tampered or outdated one is refused in words and never shown as a
partial run, and the display name is shown as text and never interpreted as markup.

## Out of scope

- Comments, reactions or any reply to a shared run.
