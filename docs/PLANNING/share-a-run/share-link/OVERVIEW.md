## Summary

A player copies a link that carries their run as it stands, to post wherever they like.

## Why

Sharing with the community is how the challenge is meant to be seen, and the charter puts that in a
link rather than a feed. Delivers FR-40, FR-43 and NFR-P2. The run travels in the link's fragment,
which a browser never sends to a server (SRS, Data map).

## Out of scope

- What the person opening the link sees — `view-shared-run`.
- A link that updates as the run goes on. That needs a server; a link is a snapshot.
- Shortening links through a third-party service. It would send the run to that service.
