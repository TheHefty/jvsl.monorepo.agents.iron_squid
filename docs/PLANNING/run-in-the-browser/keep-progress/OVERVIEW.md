## Summary

A run survives the browser being closed, and a player can carry it to another browser or device as a
file.

## Why

A run of 130 wins takes weeks. Delivers FR-30 to FR-33. There is no server, so the browser is the
only place a run lives, and the file is the player's own backup of it.
