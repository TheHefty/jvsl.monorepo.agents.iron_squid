## Summary

When a player loses their last life, the run goes back to the start and the player has to win again
with every set already conquered, in order, before anything new is drawn.

## Why

This is the rule that makes Iron Squid hard: "in the event of a loss, participants must return to
the beginning and replay with the weapons and gear they have already triumphed with". Delivers
FR-18 and FR-19.
