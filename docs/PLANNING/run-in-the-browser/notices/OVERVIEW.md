## Summary

A visitor can find, from any page, what the site keeps about them, the terms they use it under, how
to report a security problem, and that it is a fan project with no tie to Nintendo.

## Why

The site is public, so the terms and the privacy notice must be reachable (FR-50, Marco Civil art.
7), and it shows Nintendo's names and images, so it says whose they are (FR-51). The privacy notice
is the data map from the SRS in the reader's words.
