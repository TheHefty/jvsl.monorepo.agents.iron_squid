## Summary

A player starts a run and is given a set — a kit with a headgear, a clothing and a shoes piece — that
they can neither skip nor re-draw.

## Why

The draw is the challenge: "skipping weapons or gear is not permitted". Delivers FR-10 to FR-14 and
FR-23. The order of every draw is fixed when the run starts, which is what stops undo (FR-20) from
becoming a way to re-roll.
